# FormCraft 低代码表单搭建器

基于 Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router 与 VueUse 构建。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

测试：

```bash
pnpm test        # 单元 / 集成测试（vitest）
pnpm e2e         # 端到端冒烟（需 dev server 已启动，依赖 playwright）
```

## 已实现

- 左侧组件库拖入画布，支持输入框、选择器、日期、表格、分组、自定义容器。
- 节点递归渲染与拖拽排序，分组和容器支持嵌套落点。
- 右侧属性面板配置标题、字段名、占位提示、表格列、校验规则和条件显隐。
- 画布 Schema 可导出、导入 JSON。
- 基于快照的撤销重做、删除、复制节点。
- 实时预览页面可填写数据并展示条件显隐、必填、长度、正则和范围校验结果。
- **按字段路径合并的离线修订**：多个标签页同时编辑不再整份覆盖（见下节）。

## 离线修订与发布基线

设计器不再只保存一份本机草稿，而是「发布基线 + 草稿修订」两层结构：

- **提交修订**：每个标签页的改动经 diff 生成修订批次，携带操作号（opId）、基线版本和本侧按字段路径寻址的改动（`set:<字段id>:<属性>` / `add` / `remove` / `move` / `meta:title` 等）。
- **合并**：不同路径的改动直接合入；同一路径被两个标签页改成不同值时保留双方值，先写入者临时生效，等待在「修订与发布」面板中采用某一侧。
- **幂等与重试**：同号（opId）重放只生成一次修订；localStorage 写入失败时批次保留在本侧文档中，可继续重试且不会重复生成。持久化采用读-改-写，先并入其他标签页已写入的修订再落盘，避免整份覆盖。
- **失效重算**：合并结果一改动即推进 `mergeVersion`，相关联动条件与预览立即重算；预览始终以合并结果为准。
- **悬空引用**：分组被移动或移除后，指向其中字段的联动条件列入「待修复」，对应字段在预览中隐藏，且挡住发布，可定位字段或一键清除条件。
- **发布**：无冲突、无悬空引用、无写入失败时才允许发布；发布后合并结果固化为新基线，草稿修订归档重新计数。
- **迁移**：检测到旧版无版本信息的本地草稿（`formcraft-schema-v1`）时，先迁移为基线 v1 并完整保留原内容，旧 key 清除前留有备份。

核心代码：

- `src/utils/revision.ts` — 字段路径 diff、合并、冲突检测、悬空引用检测、草稿文档并集、旧稿迁移（纯函数）。
- `src/stores/revision.ts` — 基线/草稿持久化、提交/重试/解决冲突/发布、跨标签页 storage 同步。
- `src/stores/designer.ts` — 画布工作副本，防抖 diff 提交修订，远端合并自动采纳。
- `src/components/RevisionPanel.vue` — 冲突处理、悬空修复、发布入口。
